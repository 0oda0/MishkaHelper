# Mishka Helper

Неоновый системный помощник для Windows 11: все регуляторы, мониторинг железа, устройства, очистка, защита, горячие клавиши, радиальное меню и виджеты в одном приложении.

## Что умеет

| Раздел | Возможности |
|---|---|
| **Главная** | Нагрузка CPU/GPU/RAM/диска, быстрые плитки, режим работы, профили, кнопка «Ускорить всё» |
| **Управление** | Громкость, микрофон, микшер приложений, выбор вывода/ввода, яркость, частота и разрешение экрана, ночной свет, режим питания и схемы, тайм-ауты экрана/сна, батарея (износ, циклы), Wi-Fi/Bluetooth/самолёт, «Не беспокоить», тёмная тема, игровой режим, скорость и ускорение мыши, тачпад |
| **Система** | Живые графики, температуры и вентиляторы, история за неделю, накопители и их здоровье (SMART), топ процессов |
| **Устройства** | Наушники, мыши, клавиатуры, геймпады, флешки: заряд, отключение/включение, извлечение, сопряжение Bluetooth, звук по умолчанию, автопереключение на наушники |
| **Nitro** (Acer) | Режимы Тихий/Баланс/Производительность/Турбо, вентиляторы (авто/макс/вручную), RGB-клавиатура по 4 зонам и эффекты — без NitroSense |
| **Ускорение** | Очистка %TEMP%, Windows\Temp, корзины, кэшей браузеров, миниатюр, дампов, логов, обновлений, шейдеров, драйверов, DISM; автозагрузка; большие файлы; дубликаты; удаление программ; расписание |
| **Защита** | Microsoft Defender (быстрая/полная/выборочная проверка, базы, угрозы, карантин), VirusTotal по хэшу, поиск подозрительного в автозагрузке, задачах, службах и процессах; проверка по расписанию |
| **Инструменты** | Окна поверх/прозрачность/убить зависшее, пипетка, таймер выключения, «не засыпать», гибернация, пинг, тест скорости, пароли Wi-Fi, сброс сети, точка восстановления, SFC/DISM, оптимизация дисков, история сбоев, кто использует камеру/микрофон, генератор паролей, хэши, пустые папки, авто-тема, лимит громкости |
| **Профили** | «Игра», «Учёба», «Батарея», «Ночь» и свои; авто-переключение по зарядке и по запуску игры |
| **Горячие клавиши** | Всё переназначается; радиальное меню (Ctrl+Alt+R) с профилями, звуком, программами |
| **Виджеты** | 20 штук: система, заряд, часы и погода, сеть, звук, профили, программы, заметки, дела, помодоро, «сейчас играет», пинг, микрофон, диски, календарь, курсы ЦБ, процессы, вентиляторы, мировое время, обратный отсчёт |

Полный список фишек и планов — в [ROADMAP.md](ROADMAP.md).

## Установка

Из [Releases](../../releases) — две редакции:

- **`MishkaHelper-Setup-x.y.z.exe`** — полная, с голосовым помощником Джарвисом;
- **`MishkaHelper-Lite-Setup-x.y.z.exe`** — Lite, всё кроме Джарвиса (меньше и легче).

Есть и портативные `…-Portable-x.y.z.zip`. Обновляется прямо из приложения: «Настройки → О программе → Обновить». Все функции со скриншотами — кнопка «Что можно сделать» в приложении ([docs/features](docs/features/index.html)).
Приложению нужны права администратора (Defender, вентиляторы, системная очистка). Автозапуск идёт через планировщик задач, поэтому UAC при входе в Windows не появляется.

> Exe не подписан цифровой подписью, поэтому SmartScreen может предупредить при первом запуске: «Подробнее» → «Выполнить в любом случае».

## Сборка

```bash
dotnet build src/MishkaHelper.csproj
```

Папка с программой (не single-file: нативным библиотекам распознавания речи и GPU нужна обычная раскладка):

```bash
dotnet publish src/MishkaHelper.csproj -c Release -r win-x64 --self-contained -o publish
```

Редакция Lite (без Джарвиса):

```bash
dotnet publish src/MishkaHelper.csproj -c Release -r win-x64 --self-contained -p:Flavor=Lite -o publish-lite
```

Релиз (установщик + портативная версия) собирается в GitHub Actions по тегу `v*`.

Отладка интерфейса: `MishkaHelper.exe --shots <папка>` сохраняет скриншоты всех страниц.

## Технологии

C# / .NET 9 / WPF, NAudio (CoreAudio), WMI (яркость, батарея, Defender, Acer gaming WMI), WinRT (Bluetooth, радио), RegisterHotKey. Без драйверов ядра: температуры на Acer читаются через встроенный WMI-интерфейс ноутбука.
