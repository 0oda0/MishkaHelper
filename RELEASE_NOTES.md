## Что нового в 2.0.0

**Игровой помощник: база знаний по игре на русском**
- Запускаешь игру — Mishka предлагает собрать по ней базу. Источники: Steam, Википедия, вики игры и PCGamingWiki, а нейросеть раскладывает всё по-русски:
  - этапы и сюжет (спойлеры дальше твоего этапа скрыты, пока сам не откроешь);
  - локации, боссы с тактикой, задания, персонажи, механики, предметы;
  - проблемы игры и их решения.
- Открывается по Ctrl+Alt+F1 и только в той игре, к которой собрана. Окно поверх игры (в оконном режиме и «без рамки») или обычным окном на втором мониторе.
- Есть поиск по-русски и по оригинальным названиям, фильтры по типу и этапу. Если чего-то нет в базе, поиск сам найдёт это на вики и допишет.
- Можно спросить: «как победить…», «где найти…» — ответ строится по базе, без спойлеров.
- На телефоне: новая вкладка «Игра». Читаешь базу, не сворачивая игру.
- Страница «Игры»: все базы, обновить, удалить, добавить игру по названию или по окну.
- Для сборки нужна нейросеть. Лучше всего бесплатный ключ Groq (подключается на той же странице); подойдёт и локальная модель Джарвиса, но русский текст у неё проще.

**Один установщик с галочками**
- Вместо четырёх редакций теперь один установщик: отмечаешь, что ставить — Джарвис, секретарша, игровой помощник. Инструменты есть всегда.
- Состав меняется в «Настройки» → «О программе» → «Состав программы», без переустановки: переключил, перезапустил.
- Старые Lite, Jarvis и Secretary обновятся сами и сохранят свой состав.

**Ещё**
- Если онлайн-нейросеть просит подождать минуту из-за лимита, Mishka ждёт сама, а не выдаёт ошибку.
