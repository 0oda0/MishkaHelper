- [ ] Ctrl+Alt+U: продиктовать «завтра в 18 тренировка» — появились заметка и напоминание с верной датой.
- [ ] Открыть расписание в браузере, Ctrl+Alt+S — адрес верный, галочка «в сводку» уже стоит; при двух окнах браузера запомнилось то, что на экране.
- [ ] Ctrl+Alt+E в программе, написать заметку, переключиться и вернуться (после перезапуска) — заметка всплыла один раз.
- [ ] Подключить почту паролем приложения — вход проходит, старые письма не сыплются, новое письмо даёт уведомление и остаётся непрочитанным.
- [ ] Скопировать «встреча завтра в 15:00» — предложение напомнить; нажать — напоминание создано.
- [ ] «Где я остановился»: «Вернуть» открывает только то, что закрыто.
- [ ] «Загрузки»: «Разложить» спрашивает подтверждение; файл на месте в новой папке.
- [ ] В игре на весь экран уведомления секретарши не всплывают, а ждут в списке «Пока ты был занят».
- [ ] Нажать «10 мин» на настоящем напоминании — через 10 минут оно приходит снова.
- [ ] «Каждый день в <время через 2 минуты> проверка»: срабатывает и переносится на завтра.
- [ ] «Когда открою Блокнот, проверка»: открыть Блокнот — уведомление, повторно не появляется.
- [ ] Запомнить страницу расписания со сводкой: на странице «Секретарша» видны пары на сегодня.
- [ ] Выделить текст на сайте, Ctrl+Alt+X: заметка с адресом, прежний текст снова в буфере.
- [ ] Правило «лаба» → папка: скачать файл «лаба.pdf» — сам перешёл, недокачанный не трогает.
- [ ] Набор с профилем и «Не беспокоить» открывается с телефона.
- [ ] Телефон: вкладка «Дела», запись, галочка; выключение с телефона показывает несделанное.
- [ ] Настройки: сохранить копию, удалить заметку, загрузить копию — заметка вернулась.
- [ ] Телефон: кнопка «Разрешить» в карточке связи открывает системный запрос; «Открыть автозапуск» открывает экран MIUI.
- [ ] Утром (первое включение за день) окно секретарши открылось само и не забрало фокус.
