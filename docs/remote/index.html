Mishka Remote

Bluetooth: телефон рядом с ПК (до ~10 м), в Mishka Helper включён «Пульт по Bluetooth». Сопряжение не нужно. Android — Chrome; iPhone — браузер Bluefy (Safari не умеет Bluetooth).

PIN из Mishka Helper → Инструменты → «Пульт с телефона»

Общий буфер обмена



Взятый текст выделится — нажми «Копировать» на телефоне.

Файлы и буфер — только по Wi-Fi: по Bluetooth слишком медленно.

Тап по картинке — клик в это место, долгое нажатие — правый клик. Обновляется ~2 раза в секунду.

Экран по Bluetooth не показать — он в сотни раз медленнее Wi-Fi. Открой пульт по Wi-Fi-адресу или для доступа из любого места включи RustDesk в Mishka Helper → Инструменты.
