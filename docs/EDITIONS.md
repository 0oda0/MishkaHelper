**Что скачать**

- **MishkaHelper-Setup** — установщик. Галочками выбираешь, что поставить: Джарвиса, секретаршу, игрового помощника (инструменты есть всегда). Состав можно поменять потом в «Настройки» → «О программе».
- **MishkaHelper-Portable** — без установки, включено всё; лишнее выключается там же, в настройках.
- **Mishka-Phone.apk** — приложение для телефона.
- Файлы с Lite, Jarvis или Secretary в названии нужны только для обновления старых версий: качать их не нужно.
