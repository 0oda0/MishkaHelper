## ⚠ Сделано, но вживую не проверено

**Джарвис**
- Живой микрофон: пороги детектора речи на реальном шуме (вентиляторы, музыка), слово «Джарвис» с вашим голосом. Проверено только на синтезированной речи.
- Новые голоса Microsoft в установленной (админской) версии — проверено только в тестовой копии.
- Чтение сайта с логином (WebView2 под правами администратора).
- Подсказки по ситуации (перегрев, «Экономия» на зарядке, 2 часа игры) — логика есть, реального срабатывания не видел.
- Сценарии по событиям (наушники, флешка, зарядка, запуск программы) и по времени.

**Приложение**
- Кнопка «Обновить» в установленной версии (ждёт вашей проверки; портативное обновление проверено).
- Установщик Lite — ни разу не ставился; портативные zip из CI на чистом ПК.
- У друзей: Windows 10, видеокарты AMD/Intel, ноутбуки не Acer, ПК без батареи.
- Ночной свет и «Не беспокоить» (через реестр — Windows может не подхватить без перезахода).
- Тачпад вкл/выкл, извлечение флешки, сопряжение/«забыть» Bluetooth.
- Кнопки «Инструментов»: сброс сети, SFC/DISM, точка восстановления, гибернация, таймер выключения, пароли Wi-Fi.
- Удаление программ, переключатели автозагрузки, поиск дубликатов, восстановление из карантина Defender, VirusTotal (нужен ключ).
- Плановые очистка и проверка, автопрофили по зарядке и запуску игр, приоритет процесса.
- Долгая работа в трее: память и CPU за сутки (утечки не искали).
- Виджеты/радиальное меню на втором мониторе с другим DPI.

## 🐞 Известные проблемы и риски

- Голоса Microsoft — неофициальный доступ (как в браузере Edge). Может перестать работать без предупреждения → тогда Джарвис сам уйдёт на офлайн-Piper.
- Whisper turbo рассчитан на видеокарту; на слабых ПК без GPU распознавание будет медленным — автоподбора модели под железо пока нет.
- Деинсталлятор не удаляет скачанные модели (~3–8 ГБ в `%LocalAppData%\MishkaHelper\models`).
- Релизы: запуск сборки по тегу на GitHub приходит с опозданием на 20–60 мин → собираю вручную и отменяю дубль.
- Приложение всегда работает с правами администратора — удобно для функций, но всё, что оно запускает (браузер, llama.cpp), тоже админское.
- В журнале иногда пишутся ошибки счётчиков GPU (процесс исчез между опросами) — безвредно.

## 💡 Как ещё улучшить (по пользе)

1. **Редактор сценариев** — визуальный конструктор «Когда… → Сделай…» с кнопкой «Проверить шаг».
2. **Джарвис живее:** говорит, пока ещё думает (стриминг), можно перебить словом «стоп»; режим диалога — после ответа 8 секунд слушает без «Джарвис».
3. **Автонастройка под железо:** видеокарта ≥6 ГБ → Whisper turbo + 4B; слабый ПК → Vosk + 1.7B. Одна кнопка «Настроить Джарвиса».
4. **Календарь и почта без ключей:** ссылка ICS (Google/Яндекс-календарь) → «что у меня сегодня?»; почта по IMAP — по желанию.
5. **Пульт с телефона:** веб-страница в домашней сети — громкость, музыка, профили, выключить ПК.
6. **Отдельный детектор слова «Джарвис»** (openWakeWord, ONNX) — меньше нагрузки, чем постоянный Whisper.
7. **Экранное время:** сколько сидел в каких программах и играх за день/неделю.
8. **История буфера обмена с поиском** и закреплёнными фрагментами.
9. **Подпись exe** через SignPath (бесплатно для OSS) — уйдёт предупреждение SmartScreen.
10. **Юнит-тесты** на разбор команд Джарвиса (числа, составные фразы) — дёшево и ловит регрессии.
11. **Деинсталлятор с галочкой «удалить модели и настройки».**
12. Резервная копия настроек одной кнопкой (файл/облако) и перенос на другой ПК.
