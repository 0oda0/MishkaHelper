## 🐞 Известные проблемы и риски

- Голоса Microsoft — неофициальный доступ (как в Edge). Может перестать работать → Джарвис сам уйдёт на офлайн-Piper.
- Пульт работает по HTTP (без шифрования) внутри домашней сети; PIN защищает от соседей по Wi-Fi, но в общественных сетях пульт лучше не включать (правило брандмауэра и так только для «Частной» сети).
- Экранное время считает «простоем» 3 минуты без мыши/клавиатуры — фильм без касаний перестаёт считаться.
- Две копии приложения одновременно (установленная + тестовая) делят порт нейросети; для тестов задавайте `MISHKA_LLAMA_PORT`.
- Релизы: запуск сборки по тегу приходит с опозданием → собираю вручную и отменяю дубль.
- Приложение всегда с правами администратора. С 0.7.0 его файлы в защищённой папке, а программы и сайты открываются с обычными правами; но встроенный браузер для сайтов Джарвиса (WebView2) работает внутри приложения — с правами админа. Портативная версия лежит в папке пользователя — её exe можно подменить, для безопасности лучше установщик.
- Пульт по Wi-Fi — HTTP без шифрования внутри домашней сети; PIN (6 цифр, блокировка при подборе) защищает от соседей, но в чужих сетях пульт не включай.

## 💡 Что ещё можно улучшить

1. Подпись exe через SignPath — уйдёт предупреждение SmartScreen (нужен твой аккаунт).
2. Русский детектор слова «Джарвис» (обучить openWakeWord на синтезированных образцах).
3. Пульт: QR-код адреса на странице, HTTPS с самоподписанным сертификатом.
4. Экранное время: лимиты («не больше 2 ч игр в день») с предупреждением.
5. Синхронизация резервной копии в облако (OneDrive-папка).
